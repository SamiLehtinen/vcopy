NAME
       vcopy - directly browseable, zero-link, multi-platform backup and sync
               tool with historical versioning

SYNOPSIS
       vcopy [OPTIONS] [SOURCES... DEST] [COMMAND]
       vcopy manual [--markdown]
       vcopy --manual | --manual-markdown

DESCRIPTION
       vcopy is a zero-dependency, static CLI backup and filesystem
       synchronization tool written in pure Rust. It creates directly
       browseable, uncompressed filesystem mirrors on external drives and
       non-snapshotting filesystems (exFAT, FAT32, NTFS, ext4, APFS) while
       preserving a full point-in-time historical change record.

       The binary embeds its complete documentation in both plain text and
       Markdown formats, allowing complete standalone operation without
       external documentation files or packages.

QUICK START & SIMPLE EXAMPLES
       Usage first! The following examples demonstrate common backup tasks:

   1. Basic Single Directory Backup
       Syncs /home/user/documents into /mnt/usb/backup:

           $ vcopy /home/user/documents /mnt/usb/backup

       Live files are directly browseable at /mnt/usb/backup/documents/ as
       regular, uncompressed files. Historical snapshots are archived under
       .version-history/.

   2. Multiple Sources
       Pass multiple source directories or files positionally or with the
       -s / --sources flag:

       Positional syntax (destination is always the final argument):
           $ vcopy /home/user/docs /home/user/photos /home/user/music /mnt/usb/backup

       In the destination mirror, distinct top-level source folders are kept:
           /mnt/usb/backup/
           |-- docs/
           |-- photos/
           `-- music/

       Using explicit -s / --sources and -d / --dest flags:
           $ vcopy -s /home/user/docs -s /home/user/photos -d /mnt/usb/backup

       Excluding unwanted files or folders (-e / --exclude, --exclude-from, .vcopyignore):
           # Exclude temporary files and build folders
           $ vcopy -e "*.tmp" -e "node_modules/" -e "target/" /home/user/code /mnt/usb/backup

           # Exclude patterns listed in an ignore file
           $ vcopy --exclude-from .gitignore /home/user/code /mnt/usb/backup

           # Any .vcopyignore file located in source directories is auto-applied

       Reading source paths from files, wildcards, or stdin (-f / --paths-from):
           # Read paths from a list file (one per line, # for comments)
           $ vcopy -f project_paths.txt -d /mnt/usb/backup

           # Read paths matching file glob patterns
           $ vcopy -f "backups_*.txt" -d /mnt/usb/backup

           # Pipe paths directly from find via standard input ('-')
           $ find /home/user/code -name "*.rs" | vcopy -f - -d /mnt/usb/backup

   3. Numbered Versions in a Flat Directory (--flat)
       When you want all files in a single flat directory without nested
       subfolders (ideal for flat USB drives, camera card ingests, or single-
       folder cloud buckets), use --flat (or --flatten).

       Every file is placed directly in the destination root. Historical
       revisions receive monotonic numbered version suffixes (.v0, .v1, ...):

           $ vcopy --flat /home/user/docs /home/user/photos /mnt/usb/backup

       Destination layout with numbered versions:
           /mnt/usb/backup/
           |-- report.pdf                     # Current live version (latest)
           |-- report.v0.pdf                  # Oldest historical version (v0)
           |-- report.v1.pdf                  # Second historical version (v1)
           |-- photo.jpg                      # Current live photo
           |-- photo.v0.jpg                   # Prior version of photo
           |-- notes_from_docs.txt            # Stem collision disambiguated
           |-- notes_from_photos.txt          # Stem collision disambiguated
           |-- notes_from_photos.v0.txt       # Historical version of notes
           |-- .version-history.lock          # Advisory concurrency lock
           |-- .version-history.baseline.json # Live state manifest & checksums
           `-- .version-history.manifest.jsonl# Append-only snapshot ledger

   4. Zero-Obfuscation Configuration Files (-c / --config)
       No separate manual or syntax to learn! A configuration file uses the
       exact same command-line flags and parameters you type in the terminal:

           $ vcopy -c backup.conf

       Direct CLI arguments format (backup.conf):
           # backup.conf - exact same flags as the command line!
           --sources /home/user/documents
           --sources /home/user/photos
           --dest /mnt/usb/backup
           --flatten
           --preserve-permissions
           --keep-daily 7
           --keep-weekly 4

       Simple key-value format (backup.conf):
           dest = /mnt/usb/backup
           sources = /home/user/documents, /home/user/photos
           flatten = true
           preserve-permissions = true
           keep-daily = 7
           keep-weekly = 4

       TOML format (backup.toml):
           dest = "/mnt/usb/backup"
           sources = ["/home/user/documents", "/home/user/photos"]
           flatten = true
           preserve-permissions = true
           keep-daily = 7
           keep-weekly = 4

   5. Listing Snapshots (list, ls)
       View historical snapshots, transfer metrics, and file change counts:

           $ vcopy ls /mnt/usb/backup

       Output:
           Snapshot                   Copied     Modified   Deleted    Transferred             
           ------------------------------------------------------------------------------------
           2026-11-09_083000          142        0          0          11.9 MB (12,491,024 B)  
           2026-11-09_091500          3          12         1          441.4 KB (452,010 B)    
           2026-11-09_100000 (live)   0          0          0          0 B                     

   6. Point-in-Time & Partial Restore
       Restore files to an exact prior snapshot or the latest mirror:

           # Restore latest live mirror
           $ vcopy restore /mnt/usb/backup /tmp/restored

           # Restore files as they existed at a specific snapshot timestamp
           $ vcopy restore -t 2026-11-09_083000 /mnt/usb/backup /tmp/restored

           # Restore a single file only
           $ vcopy restore /mnt/usb/backup /tmp/restored documents/report.pdf

           # Restore a directory subtree or glob pattern
           $ vcopy restore -i "docs/" /mnt/usb/backup /tmp/restored
           $ vcopy restore --filter "*.jpg" /mnt/usb/backup /tmp/restored

           # Restore with POSIX permissions and Windows readonly attributes
           $ vcopy restore -p -t 2026-11-09_083000 /mnt/usb/backup /tmp/restored

   7. Integrity Verification & Bit-Rot Detection (verify, check)
       Verify backup mirrors and historical snapshots against recorded CRC32 hashes:

           # Full bit-rot check (reads and recomputes SIMD CRC32 for every file)
           $ vcopy verify /mnt/usb/backup

           # Quick check (compares file sizes and timestamps, skipping full file reads)
           $ vcopy check --quick /mnt/usb/backup

   8. Retention & Snapshot Pruning
       Prune old snapshots using count limits or GFS schedules:

           # Retain only the newest 5 snapshots
           $ vcopy prune -n 5 /mnt/usb/backup

           # Retain 24 hourly, 7 daily, 4 weekly, 12 monthly, and 1 yearly snapshots
           $ vcopy prune --hourly 24 --daily 7 --weekly 4 /mnt/usb/backup

           # Dry run: preview which snapshots would be deleted without writing
           $ vcopy prune -n 5 --dry-run -v /mnt/usb/backup

OPTIONS
   Core Options:
       -s, --sources <PATH>
              Explicit source directory or file. Can be specified multiple
              times or comma-separated. Alias: --source.

       -d, --dest <PATH>
              Destination backup directory. Overrides positional destination.
              Alias: --destination.

       -f, --paths-from <PATTERN_OR_STDIN>
              Read source paths from a text file, glob pattern (e.g. backups*),
              or stdin ('-'). Can be specified multiple times.
              Aliases: --files-from, --sources-from.

       -c, --config <FILE>
              Path to configuration file. Accepts direct CLI arguments format,
              plain key-value, TOML, or JSON.

       -e, --exclude <PATTERN>
              Exclude files or directories matching glob pattern (e.g. *.tmp,
              node_modules/, target/, .DS_Store). Can be specified multiple times.

       --exclude-from <FILE>
              Read exclude glob patterns from a file (one per line, e.g. .gitignore).
              Can be specified multiple times.

       --flat
              Single-directory flat mode: stores all live and historical files
              directly in destination root using .v0, .v1 version numbers.
              Alias: --flatten.

       --flat-date
              In flat mode, use timestamp in archived version names
              (<stem>.<YYYY-MM-DD_HHMMSS>.<ext>) instead of monotonic .v<N>.

       -p, --perms
              Record POSIX mode bits (Unix) and readonly attributes (Windows)
              in manifests and restore them on compatible filesystems.
              Aliases: --preserve-permissions, --permissions.

       -t, --time <TIMESTAMP>
              Target snapshot timestamp (YYYY-MM-DD_HHMMSS or prefix) or
              'latest' for restore or verify.
              Aliases: --target-time, --snapshot.

       -i, --include <PATH_OR_GLOB>
              In restore mode, restore only files matching the given path,
              prefix directory (e.g. docs/), or glob pattern (*.pdf).
              Alias: --filter.

       -F, --force
              Force execution, bypassing safety circuit breakers (100% loss,
              foreign directory, missing source).

       --allow-existing
              Allow destination or restore target directory to contain pre-
              existing foreign files without error.

       --allow-empty-source
              Allow empty source without tripping the 100% deletion safety
              circuit breaker.

       --allow-missing-source
              Allow missing source paths without aborting the backup run.

       --dry-run
              Simulate execution and display planned operations without
              modifying the filesystem.

       --quick
              In verify / check mode, perform quick integrity checks using file
              sizes and timestamps, skipping full file reads and CRC32 computation.

       -v, --verbose
              Enable detailed output listing every copied, modified, and
              deleted file.

       --manual, --man
              Print this complete user manual in ASCII / man-page format.

       --manual-markdown, --manual-md, --markdown
              Print this complete user manual in Markdown format.

   Retention Policy Options (GFS & Count):
       -n, --max-versions <N>
              Retain only the newest N snapshots (overrides GFS).

       --keep-hourly <N>, --hourly <N>
              Number of hourly snapshot buckets to retain (default: 24).

       --keep-daily <N>, --daily <N>
              Number of daily snapshot buckets to retain (default: 7).

       --keep-weekly <N>, --weekly <N>
              Number of weekly snapshot buckets to retain (default: 4).

       --keep-monthly <N>, --monthly <N>
              Number of monthly snapshot buckets to retain (default: 12).

       --keep-yearly <N>, --yearly <N>
              Number of yearly snapshot buckets to retain (default: 1).

SUBCOMMANDS
       auto   (Default when no subcommand is given)
              Create backup snapshot and automatically prune old versions.

       create
              Create a new backup snapshot without running retention pruning.

       restore [OPTIONS] <DEST> <TARGET_DIR> [PATH_OR_PATTERN]
              Restore files from destination to a target directory.
              Supports full, single-file, subtree, and wildcard pattern restore.
              Use -t / --time <TIMESTAMP> to select a point in time.

       list, ls
              List all snapshots in destination with summary statistics.

       verify, check
              Verify backup integrity and detect bit-rot against recorded manifests.
              Recalculates SIMD CRC32 hashes by default; use --quick for size/mtime.

       prune  Manually prune snapshots according to retention rules.

       manual, man
              Display this complete user manual. Use --markdown for markdown.

STORAGE MODES
   1. Hierarchical Snapshot Mode (Default)
       The live mirror is stored in <dest>/ exactly matching the source.
       When a file changes, the older version is displaced into a timestamped
       directory under .version-history/<YYYY-MM-DD_HHMMSS>/.

   2. Single-Directory Flat Mode (--flat)
       All files are kept in the destination root folder:
       - Numbered versions: <stem>.v0.<ext>, <stem>.v1.<ext>, ...
       - Timestamped versions: <stem>.<TIMESTAMP>.<ext> with --flat-date.
       - Monotonic numbering behavior: version numbers are strictly monotonic
         and are NEVER shifted or renamed during snapshot pruning, preventing
         massive disk I/O thrashing and FAT32/exFAT filesystem corruption.
       - GFS Retention in Flat Mode: GFS pruning policies operate seamlessly
         on flat mode snapshot ledgers, removing expired versions without
         altering the names of retained historical files.
       - Collision disambiguation: <stem>_from_<source>.<ext>
       - Metadata: .version-history.baseline.json,
                   .version-history.manifest.jsonl,
                   .version-history.lock
       - Automatic orphan scan recovery: recovers history automatically from
         both .v<N> and timestamped flat files if metadata is missing.

SYSTEM INVARIANTS & SAFETY GUARANTEES
       1. Zero Links: Never creates or follows hardlinks, symlinks, or block
          reflinks. Destination mirrors are 100% portable across FAT32, exFAT,
          NTFS, ext4, and cloud drives.
       2. Directly Browseable: All live files and historical versions are raw,
          uncompressed files readable directly in standard OS file managers.
       3. Atomic Staging Writes: Writes to .<file>.tmp.<pid>.<id> and atomically
          renames into place to avoid partial file corruption.
       4. Nanosecond Timestamps & SIMD CRC32: Preserves nanosecond modification
          timestamps and CRC32 checksums to eliminate FAT/exFAT 2s drift.
       5. Reverse-Delta Pruning Consolidation: Pruning intermediate snapshots
          migrates displaced files into the preceding kept snapshot before
          removal, preventing data loss across restore points.
       6. Resilient Advisory Locking: Non-blocking .lock with PID file fallback.
       7. 100% Wipeout Circuit Breaker: If source directories are empty or
          unmounted, sync aborts immediately instead of deleting the destination
          mirror. Override with --allow-empty-source or -F/--force.
       8. Foreign & System Directory Guards: Refuses to overwrite root (/), user
          home, system directories, or foreign populated folders lacking vcopy
          metadata. Override with --allow-existing or -F/--force.

EXIT STATUS
       0      Success.
       1      Fatal error (e.g. invalid arguments, path collision, I/O error).
